# Запуск проекта

Для запуска проекта необходимо склонировать репозиторий.

Открыть терминал в папке проекта и выполнить следующую команду
```bash
docker-compose up --build
```

Дождаться запуска сервиса и перейти на:
1) localhost:3000 - web интерфейс сервиса
2) localhost:15672 - Интрефейс RabbitMQ


# Возможные ошибки

Если отправляемые задачи в web интресфейсе создаются с ошибкой, проверьте статус worker-ов в docker.

```bash
docker-compose logs worker
```

Если в логах обнаружены ошибка подключения, то перезапустите worker
```bash
docker-compose restart worker
```
